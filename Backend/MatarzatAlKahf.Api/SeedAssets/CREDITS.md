# Seed image credits

These authentic Palestinian heritage photographs illustrate design / embroidery motifs in a fictional development catalog. They are not photographs of actual store inventory. Product descriptions and image alternative text identify their illustrative use. Replace them with owned product photography before treating the demo catalog as real merchandise.

The 32 local JPG files use 14 distinct source photographs. Migration and startup require no external image requests. All images were downloaded as Wikimedia-generated thumbnails without further editing. Each image retains the source license below, independently of the software license. For CC BY-SA images, redistributed copies and adaptations must follow the linked share-alike license, including attribution and indication of changes.
